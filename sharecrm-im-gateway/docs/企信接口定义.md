## 1、企信发送消息给网关

### 互联侧定义

#### 入参

| 字段 | 类型 | 说明 |
|---|---|---|
| env | int | 是否互联：0 企业内，1 互联；**响应消息时需要原样带回** |
| ea | String | 会话所属企业 ea；**响应消息时需要原样带回** |
| botFullId | String | 需要响应这个消息的 botId；需要确认如何通过该信息让网关侧知道使用哪个 claw |
| sessionId | String | 企信对应的会话 ID；**响应消息时需要原样带回** |
| parentSessionId | String | 父会话 id；**响应消息时需要原样带回** |
| messageId | long | 企信侧消息 ID；目前互联侧应该暂时没用 |
| messageType | String | 主要支持文本（T）、图文（MIX）、图片（I）、文档（D）等基础消息；具体参考：`Message` 定义 |
| messageContent | String | 消息内容：文本为具体内容；其他类型为 JSON 格式；参考：`Message` 定义 |
| messageTimestamp | long | 消息发送时间戳 |
| senderFullId | String | 发送人完整 id，例如：`E.ea.employId`（如：`E.fs.7618`） |
| replyMessageId | long | 回复的消息 ID |
| historyMessages | List\<SampleMessageInfo\> | 历史消息：10 条上下文 |
| locale | Locale | 发送人的语言环境 |

## 2、网关发送消息给企信

### 企信提供 REST 接口

#### 依赖

```xml
<dependency>
    <groupId>com.facishare</groupId>
    <artifactId>fs-qixin-api</artifactId>
    <version>0.1.1-SNAPSHOT</version>
</dependency>
```

#### Bean 引用

```xml
<import resource="classpath:/spring/fs-qixin-rest-client.xml" />
```

### 入参

| 字段 | 类型 | 说明 | 是否必填 |
|---|---|---|---|
| env | int | 是否互联：0 企业内，1 互联；响应消息时需要带回来 | 否（默认企业内） |
| ea | String | 会话所属企业 ea | 是 |
| botFullId | String | 以这个助理身份进行发送 | 是 |
| sessionId | String | 企信对应的会话 ID | 是 |
| parentSessionId | String | 父会话 id | 否 |
| agentMessageInfo | String | openClaw 要发送的内容，Markdown 格式 | 是 |
| replyMessageId | int | 参考发送的 messageId | 否 |

account增加botFullId
将env,ea,sessionId,parentSessionId拼接为bot的sessionid并支持反解析,
格式为ea||env||sessionId||parentSessionId
